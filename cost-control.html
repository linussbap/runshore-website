Cost control

Know what is running. Prove it is gone.

Cloud test environments cost money while they run. RunShore can list what is still running in an AWS, Azure or Google Cloud account, check that a teardown left nothing behind, and refuses to call a destroy finished until it has proved it.

Compare cloud platforms →
Cloud Audit

Resource Inventory

A read-only scan of the cloud account, shown with live progress in the Activity panel. It reports each category that can bill, with an explicit zero when nothing is found:

AWS: EKS clusters, EC2 instances, VPCs, subnets, security groups, network interfaces, load balancers, target groups, EBS volumes, IAM roles.
Azure: AKS clusters, resource groups, VM scale sets, virtual networks, network security groups, network interfaces, load balancers, public IPs, managed disks, managed identities.
Google Cloud: GKE clusters, compute instances, VPC networks, subnets, firewall rules, forwarding rules, persistent disks, static IPs, service accounts.

Cloud Audit

Cleanup Validation

A read-only check that nothing created by the platform remains in the account. It returns CLEAN or lists what is left. First run through the Client App: AWS, eu-west-2, CLEAN, 12 November 2026.

Top bar

VERIFY

After a destroy, VERIFY runs a set of checks and reports each one as ✓ clear or ✗ still present, ending with "All clear" only when nothing is found still running.

Destroy

A destroy that proves itself

Cloud destroy runs four steps: release the cloud resources Kubernetes created, Terraform destroy, sweep leftovers, then a verification gate that fails if anything billable remains.

Workloads

Workloads stop by themselves

Load generators stop after a set time (60 minutes by default, set in ADMIN), so a forgotten test does not keep a cluster busy or fill its disks.

Local

Pause instead of rebuild

On local Kubernetes, SHUTDOWN pauses the database operators in order and keeps the data, so a restart needs no rebuild and no crash recovery.

Cost control lists and checks resources. It does not read billing data or estimate prices; use each provider's billing tools and pricing pages for amounts.
