Cloud platform choices

AWS, Azure and Google Cloud

Compare their strengths, trade-offs and workload fit. No provider is automatically best for every workload.

aws Amazon Web Services
  • Broad portfolio of infrastructure and managed services.
  • Amazon EKS for managed Kubernetes control planes.
  • Multiple architecture patterns for compute, storage and networking.
  • Well-established global infrastructure footprint.
Official EKS documentation ↗
A Microsoft Azure
  • Strong fit where Microsoft identity, Windows Server, SQL Server or Microsoft 365 are already central.
  • AKS for managed Kubernetes.
  • Azure Arc extends management across hybrid and multicloud estates.
  • Integrated governance and enterprise management services.
Official AKS documentation ↗
G Google Cloud
  • Strong data and analytics ecosystem, including BigQuery.
  • GKE offers Standard and Autopilot operating modes.
  • Autopilot can reduce node-management overhead for suitable workloads.
  • Useful fit for data-intensive and cloud-native platform designs.
Official GKE documentation ↗
