# RunShore website

Public website for RunShore, an AI-assisted database assessment and observability platform
(PostgreSQL, MySQL, MongoDB and SAP ASE/Sybase on Kubernetes, AWS, Azure and Google Cloud,
with PMM, New Relic and Splunk).

Static HTML, CSS and JavaScript, served by GitHub Pages. The `demo-story/` folder is a recorded
walkthrough of the platform; screenshots and logs have been redacted (addresses, account and
subscription identifiers).
