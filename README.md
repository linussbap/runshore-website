# RunShore website

Public website for **RunShore**, an AI-assisted database assessment and observability platform:
PostgreSQL, MySQL, MongoDB and SAP ASE on local Kubernetes, AWS, Azure and Google Cloud,
monitored with PMM, New Relic and Splunk.

**Live site:** https://linussbap.github.io/runshore-website/

**Start here (recruiters):** https://linussbap.github.io/runshore-website/recruiters.html

## About this repository

Static HTML, CSS and JavaScript, served by GitHub Pages; no build step, cookies, analytics or forms.
Screenshots and logs have been cleaned before publishing: browser bars cropped, and account numbers,
subscription IDs, cluster addresses, private IP addresses and usernames removed or blurred.
The RunShore platform's own source code is in a separate, private repository.
