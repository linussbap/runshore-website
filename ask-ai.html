ASK AI

A technical assistant that explains the work

ASK AI is being expanded to use Anthropic and OpenAI through a shared provider architecture. It should explain concepts in original language, create examples, walk through code and help investigate technical problems.

Explore LEARN → →

Two first-class AI providers

Anthropic and OpenAI are intended to be selectable through ADMIN. The provider choice should not change RunShore's shared tool permissions, repository knowledge or safety boundaries.

AnthropicOpenAI Responses APIShared tools

Official-source discipline

Technical explanations must prioritise documentation published by the product owner, developer or recognised maintainer. Answers should include specific, clickable references and original examples.

Repository-aware explanations

When asked how RunShore works, ASK AI should search the repository's real documentation and source code, identify relevant files and distinguish observed implementation from proposed changes.

Read-only operational boundaries

ASK AI should use validated, bounded read-only tools. It must not independently deploy, destroy or alter infrastructure. State-changing actions remain in deterministic application workflows with explicit approval.

The expanded two-provider integration and enhanced teaching behaviour are implementation goals. This page describes the intended experience and does not claim that every capability is already deployed.
