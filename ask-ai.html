ASK AI

An assistant that explains what happened

ASK AI is a tab in the RunShore console. It answers questions about the platform by reading its state and recorded evidence, and it cannot change anything.

LEARN →
Built

Nine read-only tools

Connection, monitoring registration, assessment, workload and replication state, resource statistics, listing and reading evidence, and searching the runbooks.

Built

Evidence first

Answers are built from RunShore's recorded evidence. Every statement is labelled as observed, stale or inferred, and tool output is treated as data, never as instructions.

Built

Official documentation

Optional web search is limited to official documentation sites, with the sources shown alongside the answer.

Built

Tutor for LEARN

From a LEARN lesson, ASK AI teaches the topic and checks exercise answers against a marking guide.

Built

Read-only by design

ASK AI cannot deploy, destroy or change anything. Every change goes through the console's own actions.

Planned

Choice of AI provider

Today ASK AI uses Anthropic, with the client's own API key. OpenAI as a second provider is planned.
